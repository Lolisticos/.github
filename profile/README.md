# Lolisticos

### Software, tecnología e innovación aplicada.

En **Lolisticos** diseñamos y desarrollamos soluciones digitales para transformar ideas, optimizar procesos y resolver problemas reales.

Trabajamos en el desarrollo de aplicaciones web, plataformas de gestión, automatización, integración de datos e inteligencia artificial.

Creemos en el software como una herramienta para mejorar la productividad, facilitar el acceso a la información y generar valor para personas, organizaciones y comunidades.

## Nuestros proyectos

**DatosAbiertos AR** — Plataforma de exploración y visualización de datos públicos argentinos, con foco en la accesibilidad, la transparencia y el análisis de información.

**DocuMind** — Plataforma de inteligencia documental que facilita la consulta, el análisis y la trazabilidad de información mediante inteligencia artificial.

**ObraControl** — Sistema de gestión y seguimiento de obras, orientado al control de avances, recursos y documentación.

*Estos proyectos se encuentran en etapa de planificación y desarrollo.*
